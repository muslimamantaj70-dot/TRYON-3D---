# Жүйеге қойылатын талаптар

## Stakeholder-лер

| № | Stakeholder | Мүддесі |
|---|---|---|
| 1 | Клиент (сатып алушы) | Өлшемін дұрыс таңдау, тауарды қайтармау, ыңғайлы интерфейс |
| 2 | Сатушы | Тауарын тез қосу, өлшем кестесі мен суретін басқару, қайтарулардың азаюы |
| 3 | Әкімші | Жүйені, рөлдерді, деректерді басқару, есеп алу |
| 4 | Менеджер | Тапсырыстар мен қайтаруларды жылдам өңдеу |
| 5 | Жеткізу қызметі (сыртқы) | Тапсырыс деректерін дұрыс алу |
| 6 | Төлем жүйесі (сыртқы) | Төлем және қайтару сұрауларын алу |
| 7 | Әзірлеуші / қолдау | Жүйені оңай қолдау және кеңейту |

## Функционалдық талаптар

| ID | Талап | Басымдық | Байланысы |
|---|---|---|---|
| FR-01 | Жүйе пайдаланушыны тіркеуге және логин мен құпия сөз арқылы авторизациялауға мүмкіндік беруі керек | Жоғары | US-09, UC-01 |
| FR-02 | Жүйе пайдаланушыға рөл (клиент, сатушы, әкімші, менеджер) тағайындап, рөлге қарай қолжетімділікті шектеуі керек | Жоғары | US-09, UC-01 |
| FR-03 | Жүйе клиентке бойын, салмағын және қалауы бойынша кеуде, бел, жамбас өлшемдерін енгізіп, профильде сақтауға мүмкіндік беруі керек | Жоғары | US-01, UC-02 |
| FR-04 | Жүйе бойы мен салмағы бойынша дене өлшемдерін шамамен бағалап, клиентке нақтылауға мүмкіндік беруі керек | Орташа | US-01, UC-02 |
| FR-05 | Жүйе тауар каталогын санат, түс, баға бойынша іздеу және сүзгілеумен көрсетуі керек | Жоғары | UC-03 |
| FR-06 | Жүйе таңдалған киімді клиент өлшемдеріне сай 3D манекенге кигізіп, 360° көрсетуі керек | Жоғары | US-02, UC-04 |
| FR-07 | Жүйе тауардың өлшем кестесін клиент өлшемімен салыстырып, сәйкес өлшемді ұсынуы керек | Жоғары | US-03, UC-05 |
| FR-08 | Жүйе қысатын, дәл отыратын және бос аймақтарды түспен көрсетуі керек | Жоғары | US-03, UC-04 |
| FR-09 | Жүйе клиентке бірнеше киімнен (топ, төменгі киім, аяқ киім) образ жинауға мүмкіндік беруі керек | Орташа | US-04, UC-06 |
| FR-10 | Жүйе себеттегі тауарды қосуға, өзгертуге, жоюға және жалпы соманы есептеуге мүмкіндік беруі керек | Жоғары | US-05, UC-07 |
| FR-11 | Жүйе тапсырыс рәсімдегенде қалдықты автоматты тексеруі керек | Жоғары | US-05, UC-07 |
| FR-12 | Жүйе төлемді сыртқы төлем жүйесі арқылы өңдеуі керек | Жоғары | UC-08 |
| FR-13 | Жүйе тапсырыс мәртебесі өзгергенде клиентке автоматты хабарлама жіберуі керек | Орташа | US-06, UC-09 |
| FR-14 | Жүйе клиентке қайтару өтінімін жасауға, менеджерге оны бекітуге мүмкіндік беруі, бекітілген соң ақшаны автоматты қайтаруы керек | Жоғары | US-08, UC-10, UC-11 |
| FR-15 | Жүйе сатушыға тауар қосуға, киім түрін таңдауға, өлшем кестесін толтыруға, фото немесе принт жүктеуге және қалдықты жаңартуға мүмкіндік беруі керек | Жоғары | US-07, UC-12, UC-13 |
| FR-16 | Жүйе әкімшіге пайдаланушыларды, санаттарды, тауарларды басқаруға және сатылым мен қайтару бойынша есеп алуға мүмкіндік беруі керек | Орташа | US-09, UC-14, UC-15 |

## Функционалдық емес талаптар

| ID | Санат | Талап |
|---|---|---|
| NFR-01 | Өнімділік | Каталог беті 2 секундтан аспай, 3D манекен 3 секундтан аспай жүктелуі керек; айналдыру кезінде кідіріс болмауы керек |
| NFR-02 | Қауіпсіздік | Құпия сөздер хэштеліп сақталуы керек; пайдаланушы өз рөлінде рұқсат етілмеген беттерді аша алмауы керек |
| NFR-03 | Қолдану ыңғайлылығы | Интерфейс қазақ тілінде; жаңа клиент киімді манекенге кигізіп көруді 3 қадамнан аспай жасай алуы керек |
| NFR-04 | Сенімділік | Тапсырыс, төлем және қайтару деректері жоғалмауы керек; дерекқордың резервтік көшірмесі жасалуы керек |
| NFR-05 | Үйлесімділік | Қосымша Windows-та терезе ретінде ашылып, WebGL қолдайтын ортада жұмыс істеуі керек |
| NFR-06 | Кеңейтілуі | Жаңа киім түрін қосу жүйенің басқа бөліктерін өзгертпей жасалуы керек |
| NFR-07 | Дәлдік және ашықтық | Өлшем ұсынысы өлшем кестесіне негізделуі керек; бойы мен салмағынан бағаланған өлшемдер «шамамен» деп белгіленуі керек |
