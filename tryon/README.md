# TryOn

> Киімді 3D манекенге виртуалды киіндіріп көруге болатын интернет-дүкен

**Пән:** Ақпараттық жүйелер негіздері · **Мамандық:** 6B06102 «Ақпараттық жүйелер»
**Жоба тақырыбы:** №3 Интернет-дүкеннің ақпараттық жүйесі

## Мәселе және идея

Онлайн киім алғанда адам өлшемін біле алмайды, сондықтан тауар қайтарылады, клиент пен сатушы екеуі де шығынға батады.
TryOn клиенттің өлшемдері бойынша 3D манекен құрады, таңдалған киімді оған кигізіп, 360° көрсетеді,
қысатын және бос жерлерді түспен белгілейді және сәйкес өлшемді ұсынады.

## Негізгі мүмкіндіктер

- дене өлшемдерін енгізу (бойы мен салмағынан шамамен бағалау немесе қолмен енгізу);
- киімді 3D манекенге кигізіп, 360° айналдыру; қысу / дәл / бос аймақтарын түспен көрсету;
- өлшем ұсыну және образ жинау («қуыршақ ойыны»);
- себет, тапсырыс, төлем, қайтару;
- сатушы панелі (тауар, өлшем кестесі, қалдық) және әкімші панелі.

## Рөлдер

Клиент · Сатушы · Менеджер · Әкімші

## Қалай іске қосу

**Дерекқорды тексеру** (Python 3 жеткілікті, SQLite кірістірілген):

```bash
python database/test_db.py
```

**3D прототип:** `prototype/mannequin.html` файлын браузерде ашыңыз (Three.js CDN арқылы жүктеледі, интернет керек).

## Командалық жұмыс ережелері

- `main` — тек жұмыс істейтін нұсқа. Тікелей `main`-ге жазбаймыз.
- Әр өзгеріс жеке branch-та жасалады: `feature/<қысқа-атау>`, `docs/<атау>`, `fix/<атау>`.
- Commit хабарламасы: `тип: не істелді` (мысалы, `docs: add fit logic`, `db: add return triggers`).
- `main`-ге Pull Request арқылы біріктіреміз, мүмкіндігінше Issue-ға сілтеме жасаймыз (`Closes #N`).
